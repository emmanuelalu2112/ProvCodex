## Cómo obtener el código actualizado de `NGproveedores-Cursor2.py`

Si al revisar un diff en GitHub sólo ves líneas con prefijos `+` y `-`, puedes copiar el
contenido completo y limpio del archivo usando cualquiera de estas opciones:

1. **Ver la versión "Raw" en GitHub**
   - Abre el archivo en la vista del repositorio.
   - Haz clic en el botón **Raw** en la esquina superior derecha.
   - Copia el contenido desde esa vista, que muestra el archivo completo sin los símbolos de diff.

2. **Descargar el archivo desde la rama**
   - En la URL del archivo, reemplaza `blob` por `raw` para descargarlo directamente.
   - Guarda el archivo descargado o ábrelo en tu editor para copiar el código.

3. **Usar la línea de comandos con Git**
   - Ejecuta `git show HEAD:NGproveedores-Cursor2.py > NGproveedores-Cursor2.py.nuevo` para crear una copia del archivo actual.
   - Abre `NGproveedores-Cursor2.py.nuevo` en tu editor y copia el contenido sin prefijos de diff.

4. **Clonar o actualizar el repositorio**
   - Ejecuta `git clone <url-del-repo>` o `git pull` en tu copia local.
   - El archivo `NGproveedores-Cursor2.py` aparecerá tal cual en tu árbol de trabajo y podrás copiarlo directamente.

Estas opciones te permiten obtener siempre la versión más reciente del archivo sin los caracteres añadidos por la vista de diferencias.

## Archivo listo para descargar

Dentro de este repositorio encontrarás también `NGproveedores-Cursor2-descarga.py`, que es una copia idéntica del código actual de `NGproveedores-Cursor2.py`. Puedes descargarlo directamente desde GitHub con el botón **Download raw file** o usando la línea de comandos:

```bash
curl -L -o NGproveedores-Cursor2-descarga.py "https://raw.githubusercontent.com/<tu-usuario>/<tu-repo>/<rama>/NGproveedores-Cursor2-descarga.py"
```

Sustituye `<tu-usuario>`, `<tu-repo>` y `<rama>` por los valores reales de tu repositorio (por ejemplo, `main` o `work`). Esto te dará un archivo limpio, listo para usar o compartir sin necesidad de copiarlo desde la vista de diferencias.
